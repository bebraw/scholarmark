# Scholarmark for VS Code

This extension adds Scholarmark syntax highlighting and language intelligence
to ordinary Markdown files.

## Features

- Theme-aware highlighting for portable comments and Scholarmark directives
- Diagnostics for citations, labels, references, bibliography markers, figures, and disclosures
- Label and citation completion
- Go to definition for labels and BibTeX citation keys
- Hover information, document symbols, folding, references, and label rename
- Authoring snippets with the `sm-` prefix

The extension looks for `bibliography.bib` at the workspace root by default.
Change `scholarmark.bibliographyFile` to use another workspace-relative path.
